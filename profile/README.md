# Openflow — exploring what an open workspace can become

Openflow is a personal proof of concept built on a preconfigured and extended openDesk installation. It explores how an open workspace can connect everyday collaboration, business applications, and data — and what becomes possible when those tools work together.

I’m building it around the workflows and capabilities I find useful, with the freedom to experiment and make opinionated choices. The aim is to demonstrate a connected working environment through practical examples.

**A work in progress, open to participation.**
